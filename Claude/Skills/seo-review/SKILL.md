# TriangeIce SEO Review

## Goal

Improve search visibility while keeping content natural, useful, accurate, and consistent with TriangeIce branding.

Do not use SEO techniques that make the website look spammy or unnatural.

## Before Making Changes

First inspect:

1. The target page.
2. Existing metadata.
3. Page title.
4. Heading structure.
5. URL structure.
6. Internal links.
7. Images and alt text.
8. Existing SEO configuration.
9. Shared components affecting SEO.

Do not immediately rewrite content without inspecting the existing implementation.

## Page Titles

Page titles should:

- Clearly describe the page.
- Be unique where appropriate.
- Include TriangeIce when useful.
- Avoid keyword stuffing.
- Match the actual page content.

Never create misleading titles.

## Meta Descriptions

Meta descriptions should:

- Accurately describe the page.
- Be written for humans.
- Naturally include important terminology when appropriate.
- Avoid keyword stuffing.
- Avoid unsupported claims.

## Headings

Check:

- One clear primary heading where appropriate.
- Logical H2/H3 hierarchy.
- Headings should describe the content that follows.
- Do not use headings only for visual styling.

Avoid skipping heading levels without a reason.

## Content

Content should:

- Match the page's actual purpose.
- Provide useful information.
- Use natural language.
- Avoid keyword stuffing.
- Avoid repetitive paragraphs.
- Avoid AI-generated filler.

Do not invent facts, statistics, research, partnerships, or environmental claims.

## Internal Linking

Look for useful internal linking opportunities.

Internal links should:
- Be relevant.
- Help users navigate.
- Use meaningful anchor text.
- Avoid excessive linking.

Do not add links simply to increase the number of links.

## Images

Check images for:

- Meaningful alt text when the image conveys information.
- Empty alt text when an image is purely decorative.
- Descriptive filenames when practical.
- Appropriate image dimensions.
- Performance considerations.

Do not stuff keywords into alt text.

## URLs

URLs should be:

- Clear
- Short where practical
- Descriptive
- Stable
- Human-readable

Avoid unnecessary parameters or confusing URL structures.

## Technical SEO

When relevant, inspect:

- Sitemap
- Robots.txt
- Canonical URLs
- Metadata
- Open Graph data
- Structured data
- Indexability
- Internal links
- Broken links
- Image optimization
- Page performance

Do not modify technical SEO configuration without understanding its existing purpose.

## Next.js Considerations

For Next.js pages, inspect the project's existing metadata implementation before changing it.

Follow the project's established approach for:
- Metadata
- Open Graph
- Canonical URLs
- Sitemap
- Robots
- Structured data

Do not introduce a second SEO system unnecessarily.

## SEO + Accessibility

Where appropriate, check:

- Image alt attributes
- Link names
- Button labels
- Heading hierarchy
- Semantic HTML

Do not treat accessibility fixes as keyword opportunities.

## Final SEO Audit

Before completing an SEO task, verify:

- Page title is appropriate.
- Meta description is accurate.
- Heading hierarchy is logical.
- Content is useful and natural.
- Internal links are relevant.
- Images have appropriate alt text.
- URLs are clean.
- No unsupported claims were introduced.
- TriangeIce is spelled exactly as "TriangeIce".
- Existing SEO configuration was not unnecessarily duplicated or broken.
